## Tentang Repository

Repository ini berisi dokumentasi, latihan, eksperimen, dan mini project selama mempelajari **Tailwind CSS** secara bertahap.

Pembelajaran dimulai dari konsep dasar seperti utility classes, spacing, typography, colors, layout, dan responsive design, kemudian dilanjutkan menuju penggunaan Tailwind untuk membangun komponen dan halaman web yang lebih kompleks.

Repository ini dibuat sebagai **learning log**, sehingga setiap materi tidak hanya berisi teori, tetapi juga praktik dan hasil eksperimen kode.

---

## Tujuan Belajar

Target utama dari pembelajaran Tailwind CSS ini adalah:

* Memahami konsep utility-first CSS.
* Memahami cara kerja utility classes Tailwind.
* Mampu membuat layout menggunakan Flexbox dan Grid.
* Mampu membuat desain responsive.
* Memahami typography, colors, spacing, sizing, dan positioning.
* Mampu membuat komponen UI menggunakan Tailwind.
* Mampu mengubah desain dari HTML/CSS biasa menjadi Tailwind.
* Mampu menggunakan Tailwind dalam project frontend modern.
* Menjadi lebih siap menggunakan framework seperti React dan Next.js.

## Fokus Pembelajaran

Beberapa prinsip yang digunakan selama belajar:

**1. Memahami, bukan sekadar menghafal**

Contoh:

```html
<div class="p-4">
```

Tidak hanya menghafal bahwa `p-4` berarti padding, tetapi memahami bahwa:

```text
p = padding
4 = nilai spacing
```

**2. Banyak praktik**

Setiap konsep akan langsung digunakan dalam kode.

**3. Menggunakan contoh website nyata**

Contoh latihan akan dibuat berdasarkan komponen yang sering ditemukan pada website seperti:

* Navbar
* Login
* Dashboard
* Card
* Form
* Profile
* Landing page

**4. Bertahap**

Tidak langsung menggunakan konfigurasi atau teknik Tailwind yang kompleks sebelum memahami fundamental CSS dan utility classes.
