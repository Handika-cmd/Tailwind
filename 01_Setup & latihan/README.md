# Setup untuk latihan  01

Untuk latihan awal, kita gunakan CDN supaya tidak perlu ribet setup Node.js dulu.

**Gunakan ini di  html di bagian `head`sebelum `body`.
```html
<script src="https://cdn.tailwindcss.com"></script>
```

Itulah yang membuat Tailwind bisa kita gunakan untuk latihan sederhana ini.
